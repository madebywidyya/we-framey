# Framey
Responsive client-side photo frame/collage editor for GitHub Pages.

## Included
HTML, CSS, JavaScript, JSON. Features include photo upload and drag/drop, templates, filters, text, decorations, backgrounds, collage mode, surprise styling, before/after, undo/redo, PNG/JPG export, local gallery, dark mode and responsive UI.

## Deploy
Upload the five files to a GitHub repository. GitHub → Settings → Pages → Deploy from branch → `main` → `/root`.
